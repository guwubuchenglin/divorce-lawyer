# 离婚律师 Skill

> 一个给 AI Agent 用的「北京资深婚姻家事律师」技能包：接案面谈的口吻，六段式的输出，1260 条民法典原文随查。
>
> 不是法律科普机器人，是会问你「房子婚前还是婚后买的、写谁的名字」然后告诉你这周该去干什么的那种。

---

## 这是什么

把一位执业 15 年的北京婚姻家事律师的工作方法，拆成一套 Agent 能直接执行的规则：

- **先分情况再出招**——协议离婚和诉讼离婚是两套打法，信息不全先问三个决定性问题；
- **一切落到证据**——每条建议必须回答「拿什么、怎么拿、存哪、合不合法」；
- **强制六段输出**——现状判断 / 核心风险 / 立即要做的事 / 证据清单 / 谈判诉讼策略 / 红线；
- **法条能查原文**——民法典 1260 条按编拆分，三部司法解释全文内置，引用前可核对。

## 核心能力

| 能力 | 说明 |
|---|---|
| 案件分诊 | 十种典型开场（出轨、家暴、抚养权、房产、彩礼、财产追踪、应诉、拖延、协议反悔、漏分财产）自动归类和分流 |
| 财产分割 | 房产六种情形、父母出资新规、股权、公积金、养老金、保险、债务，附公式与算例 |
| 抚养权 | 三段式裁判规则、抚养证据链、抚养费计算、探望权条款写法、抢孩子反制 |
| 证据与边界 | 七类证据、合法/灰色/违法三色标注、取证红线、电子证据固定方法 |
| 北京口径 | 管辖、判离概率、分割比例、费用时限，每条标注可信度等级 |
| 谈判与诉讼 | 协议离婚全流程、离婚协议六个致命陷阱、诉讼时间线、保全、调查令、庭审要点 |
| 文书 | 起诉状、保全申请、调查令申请、人身安全保护令、离婚协议、婚内财产协议、答辩状 |

## 安装

技能包就是一个目录，`SKILL.md` 在根上。把整个仓库放到任意一个技能根目录下即可。

### DeepSeek Harness

```bash
git clone https://github.com/<you>/divorce-lawyer.git ~/.dsh/skills/divorce-lawyer
```

Windows：

```powershell
git clone https://github.com/<you>/divorce-lawyer.git "$env:USERPROFILE\.dsh\skills\divorce-lawyer"
```

放好后无需重启，新开一个会话就能在技能目录里看到它。

### 其他兼容 SKILL.md 的 Agent

任何读取 `SKILL.md`（YAML frontmatter + Markdown 正文）的框架都能直接用。把它放进该框架的技能目录，或把 `SKILL.md` 的内容并入系统提示词。资源文件按 `SKILL.md` 中给出的相对路径解析到仓库根目录。

### 更新

```bash
cd ~/.dsh/skills/divorce-lawyer && git pull
```

## 设计原则

**法条与口径分开。** `references/民法典/`、`references/司法解释/` 是一字不改的原文；`references/40-北京法院实务口径.md` 是经验判断，每条标 `【明文】`「【主流】」「【经验】」「【待核】」，不把经验说成法律。

**数字只给区间，不给假精度。** 赔偿数额、家务补偿、抚养费实判额都是区间加 `【经验】` 标签，并注明「出庭前须检索本区类案」。

**纠正高频引错。** 30 天冷静期是第 1077 条不是 1076；第 1091 条只涵盖五类情形，不是「出轨就赔」。文末附易混淆条号对照表。

**红线写成清单。** 破解手机、装 GPS、买开房记录、抢孩子、朋友圈骂人，逐条写明踩的是哪一条法律、后果是什么。

## 更新法条

法律修正或出台新司法解释时：

```bash
# 重新抓取民法典七编（改 tools/build-law.mjs 里的 URL）
node tools/build-law.mjs references/民法典

# 抓取单个规范文件
node tools/fetch-doc.mjs <url> references/司法解释/24-新规.md "标题" "版本与来源" "末条条号"

# 自检
python tools/validate.py
```
