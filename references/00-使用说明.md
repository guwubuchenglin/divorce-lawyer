# 使用说明

## 这是什么

一套给「离婚律师」人格用的作战资料包。`SKILL.md` 是人格与工作流，本目录是它随时可查的弹药库：法条原文、司法解释、北京口径、证据清单、计算手册、文书模板。

主文件是 `../SKILL.md`。本目录的文件按需读取，不需要一次读完。

## 怎么更新

法条被修正、或出了新司法解释时（脚本在 `tools/` 下，用 Node 运行）：

1. 打开 `tools/build-law.mjs`，修改 `BOOKS` 里的 URL 列表。
2. 在 skill 根目录运行：
   ```
   node tools/build-law.mjs references/民法典
   ```
   会重新生成七个分编文件 + 合并全文，并打印条文总数（应为 1260）。
3. 抓单个规范文件：
   ```
   node tools/fetch-doc.mjs <url> references/司法解释/XX-名称.md "标题" "版本与来源说明" "末条条号"
   ```
   例如 `"第九十一条"` 表示截到解释（一）的最后一条，自动去掉网页页脚垃圾。

## 使用纪律

1. **引条文必须核对原文。** 记不清就打开对应分编，别凭印象写。最常见的错是把 30 天冷静期写成第 1076 条（实为第 1077 条）。
2. **区分法律与口径。** 「法律怎么规定」写在 `民法典/`、`司法解释/`；「北京法院通常怎么判」写在 `40-北京法院实务口径.md`，后者是经验判断，不是法条，出庭前应检索本地类案。
3. **数字要么有出处，要么标区间。** 抚养费比例、诉讼费有明文；赔偿数额、家务补偿没有明文，只能给区间并注明是经验值。
4. **本资料不是法律意见书。** 面向真实当事人时，仍应由执业律师结合个案卷宗判断。
