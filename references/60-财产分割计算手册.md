# 财产分割计算手册

> 所有公式都是"算法"，不是"判法"。北京各法院、甚至同一法院不同法官，对同一套房可能算出相差 20%–30% 的补偿款。**正确姿势：用两三种算法各算一遍，得出区间，谈判按上限开价、按下限守底线，诉讼时主张对自己有利的那种并说明理由。**

---

## 一、总框架：四步走

1. **定性**：哪些是共同财产，哪些是个人财产（民法典第 1062、1063 条）。
2. **定量**：每项财产的现值 / 净值。
3. **定比例**：原则均分，但按第 1087 条照顾子女、女方、无过错方；有第 1092 条情形可少分不分。
4. **定补偿**：实物归一方，另一方拿折价款；或拍卖分钱。

**永远先做一张财产清单**，别急着算某一项。清单模板见本文件第九节。

## 二、房产（占离婚财产争议的 70%）

### 2.1 情形一：婚前首付 + 登记自己名下 + 婚后共同还贷

**法律依据**：解释（一）第 78 条——判归登记方，未还贷款是其个人债务，共同还贷本息及**对应增值**由登记方补偿。

设：
- `P0` = 购买时房屋总价（首付 + 贷款本金）
- `D` = 首付（含婚前已还本金）
- `L` = 贷款本金总额
- `C` = 婚后共同还贷**本息**总额
- `V` = 离婚时房屋现值
- `Lr` = 离婚时剩余贷款本金
- `r` = 增值率 = `(V − P0) / P0`

**算法 A｜增值率法（最常用，对非登记方最有利）**

```
补偿款 = C × 50% × (1 + r)
```

**算法 B｜份额法（部分法院采用，对登记方有利）**

```
补偿款 = (C / P0) × (V − Lr) × 50%
```

两者可以差出 20%–30%，这就是谈判空间。

**算例**

> 2016 年男方婚前购房，总价 300 万，首付 120 万（男方个人财产），贷款 180 万，登记男方名下。2017 年结婚，婚后共同还贷 9 年，每月 9,000 元，本息合计 97.2 万。2026 年离婚，房屋现值 600 万，剩余贷款本金 142 万。

- `r` = (600 − 300) / 300 = **100%**
- 算法 A：97.2 × 50% × (1 + 100%) = **97.2 万**
- 算法 B：97.2 / 300 × (600 − 142) × 50% = 0.324 × 458 × 0.5 = **74.2 万**

**结论区间：74 万 – 97 万**。谈判开价 97 万，底线 74 万；诉讼主张算法 A，理由是第 78 条明确写"共同还贷支付的款项**及其相对应财产增值部分**"，增值部分应按还贷额占总房款比例分摊。

### 2.2 情形二：婚后共同购买（不论登记在谁名下）

- 原则均分，现值扣除剩余贷款后对半分。
- 调整因素：出资来源（一方父母出资多）、婚龄长短、是否孕育子女、有无过错、对房屋的贡献（装修、还贷）。
- 判归一方时：`补偿 = (V − Lr) × 50%`，剩余贷款由得房方承担。

### 2.3 情形三：父母出资（2025 年新规，务必按新规算）

**法律依据**：解释（二）第 8 条。

**（1）一方父母全额出资**

- 有赠与合同明确约定只赠与自己子女的 → 按约定，房子是子女个人财产。
- 无约定或约定不明 → 法院**可以判归出资人子女**，再综合共同生活及孕育情况、离婚过错、对家庭贡献、离婚时市价，确定是否补偿及数额。

**实务含义**：房子大概率归出资方子女，但**不等于对方一分没有**。补偿数额是自由裁量，通常低于均分。

**算例**

> 婚后购房总价 500 万，男方父母全额出资，登记男方名下，现值 800 万，无贷款，婚龄 5 年，育有一子。

- 房子判归男方。
- 补偿参考：婚龄 5 年、育有一子、女方无过错 → 北京实践中常见 **80 万 – 200 万**（约为房屋现值的 10%–25%）【经验】。
- 若婚龄仅 1 年、无子女 → 补偿可能低至 **20 万 – 60 万**。

**（2）一方父母部分出资 / 双方父母出资**

- 有约定从约定。
- 无约定 → 以**出资来源及比例**为基础，判归一方，由得房方合理补偿。

**算例**

> 婚后购房总价 500 万，首付 150 万（男方父母 100 万、夫妻共同 50 万），贷款 350 万，现值 800 万，剩余贷款 300 万，婚龄 8 年，育有一女。

- 房屋净值 = 800 − 300 = **500 万**
- 男方父母出资占比 = 100 / 500（总价）= **20%**，对应净值 100 万，视为对男方赠与 → 归男方
- 剩余 400 万按均分 → 女方 **200 万**
- 再按婚龄、孕育、过错微调（通常 ±10%）

**结论区间：180 万 – 220 万**。

### 2.4 情形四：约定"加名"但未办转移登记

**法律依据**：解释（二）第 5 条。

- 未办转移登记就离婚 → 法院可判归一方并确定补偿。
- **婚姻关系存续时间较短 + 给予方无重大过错** → 可判归给予方，补偿数额酌定。
- 注意：这条推翻了"没加名就一定能要一半"的旧理解。

**实务提示**：如果当事人已经办了加名登记，那就按共同财产处理，适用 2.2；只有"约定了但没办"才适用本条。

### 2.5 情形五：房子有贷款、双方都不要

申请拍卖、变卖，就价款分割（解释（一）第 76 条第（三）项）。北京法拍折价率通常 7–8 折，要有心理准备。

### 2.6 情形六：特殊房型

| 房型 | 处理 |
|---|---|
| 经济适用房 / 两限房 | 未满五年不能上市 → 判归一方使用，待条件成就再分割；或按"补缴土地收益后的净值"折算 |
| 央产房 | 需原单位同意上市，先查备案；不能上市的只处理使用权和出资 |
| 小产权房 / 宅基地房 | 法院一般不处理所有权，只处理使用权、出资返还、居住利益 |
| 军产房 | 产权受限，通常只处理使用权 |
| 尚未取得产权证的房 | 不判所有权归属，只判由谁使用（解释（一）第 77 条） |

## 三、存款、理财、股票、基金

```
应分割金额 = 婚内取得部分 ÷ 2
```

- 存款：以**离婚时的余额**为准，但要倒查 2–5 年流水，把异常流出加回来。
- 一方在起诉前大额取现、转给父母 → 主张第 1092 条，要求把该笔计入共同财产再分，并对该方少分。
- 理财、基金：按离婚时市值（不是本金）。
- 股票：协商不成或按市价分配有困难的，可按**数量比例**分配（解释（一）第 72 条）。
- 婚前存款的利息：个人财产；婚前存款婚后投资所得：共同财产（解释（一）第 25、26 条）。

## 四、公积金、养老金、企业年金

| 项目 | 可分割部分 | 公式 |
|---|---|---|
| 住房公积金 | 婚姻关系存续期间实际取得或应当取得的部分 | `婚内缴存总额（单位+个人）÷ 2` |
| 基本养老金 | 婚内个人实际缴纳部分及利息（未退休时不能分"预期养老金"） | `婚内个人缴纳额及利息 ÷ 2` |
| 企业年金 / 职业年金 | 婚内积累部分 | 参照养老金 |
| 军人复员费、自主择业费 | 婚姻存续年限 × 年平均值 | `费用总额 ÷ (70 − 入伍年龄) × 婚龄` |

## 五、股权

### 5.1 估值

```
股权价值 ≈ 公司净资产 × 持股比例
```

更精确要评估（收益法、资产基础法）。净资产看审计报告或年报；没报表的，申请法院委托审计。

### 5.2 分割路径（解释（一）第 73 条）

**一方持股、另一方不是股东：**

1. 双方协商一致转让部分或全部出资额 → 需**其他股东过半数同意** + 其他股东明确**放弃优先购买权** → 配偶可成为股东。
2. 其他股东半数以上不同意转让，但愿意以同等条件购买的 → 分割**转让所得**。
3. 不同意转让也不购买 → **视为同意转让**，配偶可成为股东。

**关键条文（解释（二）第 9 条）**：一方转让登记在自己名下的股权，另一方以未经同意主张合同无效的，**法院不支持**，除非证明转让人与受让人**恶意串通**。所以"他把股权转给他妈了"能不能追回，全看能不能证明恶意串通（低价、无对价、亲属、时间点临近离婚）。

**关键条文（解释（二）第 10 条）**：双方都登记为股东、章程写了各自出资额的，**不能**直接按记载比例分，仍按第 1087 条处理。

### 5.3 算例

> 男方持有限公司 60% 股权，注册资本 1000 万（婚内实缴 600 万），公司净资产 3000 万。

- 股权价值 ≈ 3000 × 60% = **1800 万**
- 女方应得补偿 ≈ 1800 × 50% = **900 万**（若认定全部为婚内取得）
- 若注册资本中 200 万是婚前实缴 → 婚前部分对应价值先扣除，再分剩余。

## 六、保险

| 类型 | 处理 |
|---|---|
| 返还型 / 年金型 / 分红型 | 分割**保单现金价值**；用共同财产缴的费用，婚内缴纳部分对应现金价值的一半补偿 |
| 消费型（医疗、意外） | 无现金价值，不分割 |
| 以子女为被保险人的 | 通常判归抚养子女一方继续缴纳，不折价 |
| 以一方为被保险人、受益人为对方 | 可变更受益人，或按现金价值补偿 |

```
补偿 = 婚内共同财产缴纳保费对应的现金价值 ÷ 2
```

## 七、车辆

```
补偿 = (二手车市场价 − 剩余车贷) ÷ 2
```

- 北京小客车指标：**不可分割、不可转让**，但可判归一方使用；另一方拿折价。别向当事人承诺"能分到一个指标"。

## 八、债务、彩礼、家务补偿

### 8.1 债务

```
共同债务 = 双方共同签名/事后追认 + 为家庭日常生活需要所负 + 债权人证明用于共同生活/经营/合意
```

- 超出家庭日常生活需要的，原则上**不是**共同债务（民法典第 1064 条第 2 款）。
- 内部约定"债务归他"不能对抗债权人（解释（一）第 35 条）。
- 虚假债务反制：要求债权人到庭、查资金流向、查借条形成时间、申请鉴定。

### 8.2 彩礼

**能退的三种情形**（解释（一）第 5 条）：未办登记；办登记但确未共同生活；婚前给付导致给付人生活困难（后两种以离婚为条件）。

**已登记且共同生活的**：原则上不退；共同生活时间短 + 数额过高的，按比例退（涉彩礼规定第 5 条）。

**返还比例参考**（经验，非标准）：

| 情形 | 返还比例区间 |
|---|---|
| 未登记、未共同生活 | 70%–100% |
| 未登记、共同生活 < 1 年 | 30%–70% |
| 已登记、共同生活 < 1 年、无子女 | 20%–50% |
| 已登记、共同生活 1–2 年 | 0%–30% |
| 已登记、共同生活 > 2 年或已育子女 | 一般 0% |

### 8.3 家务劳动补偿（民法典第 1088 条 + 解释（二）第 21 条）

```
补偿 ≈ 婚龄 × 系数 × 对方年收入占比
```

没有法定公式，法院综合：投入时间精力、对双方影响、给付方负担能力、当地居民人均可支配收入。

**北京经验区间**：普通家庭 **3–15 万**；全职多年 + 对方高收入 **20–50 万**【经验】。**必须主动主张，法院不告不理。**

### 8.4 离婚经济帮助（第 1090 条）

一方年老、残疾、重病等生活困难，另一方有负担能力的，给予适当帮助。数额酌定，通常一次性或分期。

## 九、少分或不分（第 1092 条）

适用情形：隐藏、转移、变卖、毁损、挥霍共同财产，或伪造债务企图侵占。

**北京实践的比例**：常见 **4:6 到 3:7**，情节严重的极端案例可判"不分"【经验】。

**主张要点**：
1. 证明"行为"——大额取现、向亲友转账、低价过户、注销账户、直播打赏。
2. 证明"时间点"——集中在起诉前 6–12 个月，指向性明显。
3. 证明"主观"——隐匿（换账户、用他人名义）、虚假债务（无流水）。
4. 结合《妇女权益保障法》第 67 条的**财产申报义务**：不如实申报即是不利认定的抓手。

## 十一、保全与执行

- **诉前保全 / 诉中保全**：发现对方正在转移财产，立刻申请；诉前保全后 **30 日内**必须起诉，否则解除。
- **保全费**：1000 元以下 30 元；1000 元–10 万按 1%；超 10 万按 0.5%；**上限 5000 元**（《诉讼费用交纳办法》第 14 条）。
- **担保**：法院可酌定合理数额（解释（一）第 85 条），可用保全责任险（保费约为保全金额的 0.1%–0.3%）。
- **错误保全**：申请有误造成对方损失要赔，别为了施压乱保全。
- **执行**：判决生效后对方不履行，2 年内申请强制执行；可申请查控银行存款、房产、车辆、股权、限制高消费、纳入失信名单。

## 十二、算完之后的三个自检

1. **这个数当事人能接受吗？** 如果算出来只有 20 万而当事人预期 200 万，先纠正预期，别让他带着错误期待去开庭。
2. **这个算法在本院有先例吗？** 同一个数，换个算法可能差几十万，开庭前检索本区类案。
3. **执行得到吗？** 判 200 万但对方名下无财产，就是一纸空文。**先查财产，再谈数字。**
