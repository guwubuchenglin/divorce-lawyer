# 文书模板

> 所有模板里的 `______` 和 `【】` 都要替换。金额、日期、身份证号、地址务必核对。出具正式文书前，把引用条号再核一遍。

## 一、民事起诉状（离婚纠纷）

```
                        民事起诉状

原告：______，女，____年__月__日出生，汉族，住______，
      公民身份号码：__________________，联系电话：__________。

被告：______，男，____年__月__日出生，汉族，住______，
      公民身份号码：__________________，联系电话：__________。

                        诉讼请求

一、判令原告与被告离婚；
二、判令婚生子/女______（____年__月__日出生）由原告直接抚养，
    被告自本判决生效之月起每月支付抚养费人民币______元，
    至子女年满十八周岁止；
三、判令依法分割夫妻共同财产（详见附件一《夫妻共同财产清单》），
    其中位于______市______区______路__号__单元__室房屋归原告所有，
    原告按评估价补偿被告人民币______元；
四、判令被告向原告支付精神损害赔偿金人民币______元；
五、判令被告承担本案诉讼费、保全费、评估费。

                        事实与理由

原告与被告于____年__月__日登记结婚，____年__月__日生育子/女______。

（一）夫妻感情确已破裂
【写清：何时开始矛盾、矛盾性质、是否分居及时间、是否报警、是否有家暴/出轨/恶习、
对方态度。用事实和时间点，不写形容词。】

（二）子女抚养
【写清：子女一直由谁实际抚养、在哪上学、生活环境是否稳定、
原告的抚养能力与方案、被告是否存在不利于子女的情形。】

（三）财产情况
【写清：房产购买时间、出资来源、登记情况、还贷情况；
存款、车辆、股权、公积金等；
被告是否存在隐藏、转移共同财产的行为。】

综上，原被告夫妻感情确已破裂，无和好可能。为维护原告及未成年子女的
合法权益，依据《中华人民共和国民法典》第一千零七十九条、第一千零八十四条、
第一千零八十七条、第一千零九十一条之规定，特向贵院提起诉讼，请依法判如所请。

此致
______市______区人民法院

                                        具状人（签名）：
                                        ____年__月__日

附：
1. 本起诉状副本 1 份；
2. 证据目录及证据材料 __ 份；
3. 原告身份证复印件 1 份；
4. 结婚证复印件 1 份；
5. 子女出生医学证明复印件 1 份；
6. 夫妻共同财产清单 1 份。
```

## 四、人身安全保护令申请书

```
                        人身安全保护令申请书

申请人：______，女，____年__月__日出生，住______，
        公民身份号码：__________________，电话：__________。

被申请人：______，男，____年__月__日出生，住______，
          公民身份号码：__________________，电话：__________。

                        申请事项

一、禁止被申请人实施家庭暴力；
二、禁止被申请人骚扰、跟踪、接触申请人及其相关近亲属；
三、责令被申请人迁出申请人住所（地址：______）；
四、禁止被申请人在申请人住所、工作单位、子女就读学校
    200 米范围内活动；
五、保护令有效期六个月。

                        事实与理由

申请人与被申请人系夫妻关系，于____年__月__日登记结婚。

【按时间顺序写清每一次家暴：时间、地点、手段、后果、是否报警、是否就医。
一次一段，不要概括成"经常打我"。】

____年__月__日，被申请人因______对申请人实施殴打，致申请人______
（伤情），申请人于当日__时向______派出所报警（接处警编号：______），
并于次日到______医院就诊（诊断：______）。

此后，被申请人多次通过电话、微信威胁申请人，扬言______
（附聊天记录截图、录音）。

申请人现面临现实、紧迫的人身安全危险。依据《中华人民共和国反家庭暴力法》
第二十三条、第二十七条、第二十九条之规定，特提出申请，请依法作出
人身安全保护令。

此致
______市______区人民法院

                                        申请人（签名）：
                                        ____年__月__日

附：
1. 接处警记录 1 份；
2. 家庭暴力告诫书 1 份；
3. 医院诊断证明、病历 各 1 份；
4. 伤情照片 __ 张；
5. 威胁性微信记录、录音 各 __ 份；
6. 身份关系证明 1 份。
```

**程序提示**：法院应在 **72 小时内**作出，情况紧急 **24 小时内**（反家庭暴力法第 28 条）；保护令有效期不超过 **6 个月**，可申请延长；被申请人违反保护令，可罚款、拘留，构成犯罪的追刑责（第 34 条）。

## 五、离婚协议书

```

双方自愿离婚，并就子女抚养、财产及债务处理达成如下协议：

第一条  自愿离婚
双方自愿解除婚姻关系。

第二条  子女抚养
1. 婚生子/女______由______方直接抚养，随其共同生活。

第三条  探望权
1. ______方有权于每周六上午 9:00 至周日下午 6:00 接子女共同生活，

4. ______方应配合交接，不得无故阻挠；确需变更的，应提前 48 小时通知。

第四条  房产

   相关税费由______方承担。
3. ______方于产权变更登记完成之日起__日内，向______方支付
   房屋折价补偿款人民币______元。

第五条  车辆
______牌汽车（车牌号：京______）归______方所有，______方应于
本协议生效之日起__日内配合办理过户，费用由______方承担。

第六条  存款、理财、股票、公积金、养老金
1. 双方各自名下银行存款、理财产品归各自所有，
   具体金额以本协议签订之日账户余额为准。
2. 双方各自名下住房公积金、基本养老保险个人账户存储额归各自所有。
3. 【如一方需补偿另一方，写明金额与支付时间】

第七条  公司股权
______方持有的______有限公司__%股权归______方所有，
______方不主张分割；______方一次性补偿______方人民币______元。
```

## 六、婚内财产协议（要点版）

```
                        婚内财产协议

甲方：______，身份证号：__________________
乙方：______，身份证号：__________________

甲乙双方于____年__月__日登记结婚，现就婚姻关系存续期间

第一条  婚前财产
1. 甲方婚前所有的位于______的房屋（不动产权证号：______）
   归甲方个人所有，不属于夫妻共同财产。
2. 乙方婚前所有的______归乙方个人所有。

第二条  婚后所得
1. 双方婚后各自的工资、奖金、劳务报酬归各自所有。
2. 双方婚后共同购置的______归双方共同所有，各占 50%。
3. 一方以个人财产投资所得的收益，归该方个人所有。

第三条  债务
一方以个人名义所负债务，由该方以个人财产清偿；
但相对人知道该约定的除外。

第四条  变更与撤销
本协议为双方真实意思表示，非经双方书面同意不得变更。
一方以欺诈、胁迫手段使对方在违背真实意思情况下签订的，
受损害方有权请求人民法院撤销。

第五条  生效
本协议自双方签字之日起生效，一式两份，双方各执一份。

甲方（签名）：__________        乙方（签名）：__________
____年__月__日                  ____年__月__日
```

**提示**：涉及房产赠与的，**必须办理过户或公证**，否则赠与方在过户前可依民法典第 658 条撤销。协议里写"自愿赠与"不等于锁死。

## 九、写给当事人的《下一步行动清单》（面谈后发给他）

```
【本周必须做完的 5 件事】

1. ______（例：去派出所调 3 月 12 日接处警记录，要盖章版）
2. ______（例：去银行打印本人及对方账户近 2 年流水）
3. ______（例：把手机里的聊天记录做公证，地址：XX 公证处）
4. ______（例：拍伤情照片，带时间水印，存到只有你能进的云盘）
5. ______（例：本周五前决定走协议还是诉讼，回复我）

【这 5 件事现在不能做】

1. 不要转账、取现、注销账户。
2. 不要抢孩子、藏孩子、阻止对方探望。
3. 不要在朋友圈、家族群、孩子学校说对方的事。
4. 不要签任何对方递过来的文件，先拍照发我。
5. 不要自己去查对方的开房记录、通话记录。

【下次沟通前准备好】

- 房产证 / 购房合同 / 贷款合同的照片
- 双方近 2 年银行流水
- 孩子接送、就医、家长群的记录
- 你知道的对方全部财产线索（哪怕只是"他好像在某银行有账户"）
```
