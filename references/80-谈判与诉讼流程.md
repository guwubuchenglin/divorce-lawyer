# 谈判与诉讼流程

---

## 一、两条路的对比

| 维度 | 协议离婚 | 诉讼离婚 |
|---|---|---|
| 时间 | 最快 31 天，通常 1–2 个月 | 一次判离 3–8 个月；判不离再诉 1.5–2.5 年 |
| 成本 | 几十元工本费 | 受理费 50–300 元 + 超 20 万部分 0.5% + 律师费 + 评估费 |
| 可控性 | 高，全部靠谈 | 低，结果由法官裁量 |
| 隐私 | 相对私密 | 公开开庭（可申请不公开审理） |
| 前提 | 双方自愿 + 对子女财产债务全部达成一致 | 一方不同意或谈不拢 |
| 反悔空间 | 冷静期内可撤回；登记后财产条款可诉请撤销 | 一审可上诉 |
| 强制力 | 靠自觉，不履行要另诉 | 判决可直接申请强制执行 |

**给当事人的选择逻辑**：能谈成协议就协议，谈不成再诉。但**有家暴、有转移财产、对方在拖时间**的，别在谈判桌上耗——先保全、先起诉，边打边谈。

## 二、协议离婚全流程

### 2.1 步骤

```
第 1 步  双方共同到婚姻登记机关提出申请，提交离婚协议书
第 2 步  婚姻登记机关受理，进入 30 日冷静期
第 3 步  冷静期内任何一方可撤回申请（单方到场即可撤回）
第 4 步  冷静期届满后 30 日内，双方须亲自到场申请发给离婚证
第 5 步  登记机关查明自愿且已就子女、财产、债务协商一致，发证
第 6 步  婚姻关系解除
```

**关键时限**：冷静期 30 日 + 领证期 30 日，**逾期未共同申请领证，视为撤回**（民法典第 1077 条）。

### 2.2 材料

- 户口簿、身份证（2025 年 5 月起婚姻登记全国通办、不再要求户口簿，以民政部门最新规定为准【待核】）
- 结婚证
- 离婚协议书（一式三份，双方各一份，登记机关存档一份）
- 2 寸单人近期半身免冠照片各 2 张
- 子女出生医学证明（涉及抚养的）

### 2.3 协议离婚的六个致命陷阱

1. **"各自名下财产归各自所有"** —— 一句话可能让对方名下的房、车、股权全部归他。写这句之前必须先查清双方名下财产。
2. **"无共同财产"** —— 登记后发现有房有存款，再想分就难了（要证明是离婚时未涉及的财产）。
3. **"抚养费由一方全部负担"** —— 有效，但对方日后可依解释（二）第 16 条主张，且子女必要时仍可另行主张。
4. **"房屋归子女所有"** —— 一方在过户前反悔，法院不支持撤销（解释（二）第 20 条），但**执行很难**，要靠违约条款兜底。
5. **探望权只写"随时探望"** —— 等于没写，日后必吵。
6. **债务条款"各自债务各自承担"** —— 只对内有约束力，债权人仍可向双方主张（解释（一）第 35 条）。

### 2.4 离婚协议必备条款清单

- [ ] 双方基本信息、登记时间、子女情况
- [ ] 自愿离婚的意思表示
- [ ] 子女抚养：直接抚养方、抚养费（金额、支付时间、账户、递增机制）、教育医疗大额支出分担比例
- [ ] 探望权：具体到日、时、接送地点、节假日、寒暑假
- [ ] 房产：坐落、权证号、归属、过户时间与税费承担、贷款由谁还、补偿款金额与支付节点
- [ ] 车辆：车牌、归属、过户
- [ ] 存款、理财、股票、公积金、养老金的分割
- [ ] 公司股权 / 合伙份额
- [ ] 家具家电、贵重物品
- [ ] 债务：谁承担、对内追偿
- [ ] 户口迁移（约定迁出期限与违约金）
- [ ] 违约条款（迟延支付按日万分之几计违约金；逾期过户的赔偿责任）
- [ ] 争议解决（管辖法院）
- [ ] 生效条件（自婚姻登记机关颁发离婚证之日起生效）

### 2.5 登记离婚后的三条救济路径

| 情形 | 路径 | 时效 |
|---|---|---|
| 对方不履行财产条款 | 起诉要求履行 | 3 年（民法典第 188 条） |
| 对财产分割反悔，主张欺诈、胁迫 | 起诉请求撤销财产分割协议（解释（一）第 70 条） | 撤销权 1 年 / 90 日（民法典第 152 条） |
| 离婚时未涉及的共同财产 | 起诉请求分割（解释（一）第 83 条） | 3 年 |
| 发现对方隐藏转移财产 | 起诉请求再次分割（民法典第 1092 条） | 3 年，自**发现之日**起（解释（一）第 84 条） |
| 对方不付抚养费 | 子女起诉要求支付（解释（二）第 17 条） | 抚养费不适用诉讼时效 |

## 三、诉讼离婚全流程

### 3.1 时间线

```
起诉 → 7 日内立案 → 送达被告（1–4 周，送达难可公告 30 日）
     → 排期开庭（立案后 1–3 个月）
     → 庭前调解 / 证据交换
     → 开庭（可能多次）
     → 判决（开庭后 1–2 个月）
     → 上诉期 15 日
     → 生效 / 进入二审（3 个月）
```

- 简易程序审限 **3 个月**，普通程序 **6 个月**（民诉法第 164、152 条）。
- 判不离后 **6 个月**可再诉；有新情况新理由的不受限制（民诉法第 127 条第（七）项）。

### 3.2 起诉前的准备清单

- [ ] 结婚证 / 婚姻登记记录证明
- [ ] 双方身份证信息（被告的准确住址，用于送达）
- [ ] 子女出生证明
- [ ] 财产线索清单（房产坐落、车牌号、开户行、公司名称）
- [ ] 起诉状（按被告人数 + 1 份）
- [ ] 证据目录及证据副本
- [ ] 是否申请保全（要保全的，先准备好担保）
- [ ] 是否申请调查令（列明要查的账户、机构）

### 3.3 诉讼请求怎么写（决定案子走向）

一份好的起诉状，诉讼请求要"**可执行、可分割、留余地**"：

```
1. 判令原告与被告离婚；
2. 判令婚生子/女 XXX（20XX 年 X 月 X 日出生）由原告直接抚养，
   被告每月支付抚养费 X,XXX 元至子女年满十八周岁止；
3. 判令依法分割夫妻共同财产（详见财产清单），其中位于 XX 区 XX 路 X 号
   房屋归原告所有，原告按评估价补偿被告 XXX,XXX 元；
4. 判令被告支付精神损害赔偿金 XX,XXX 元；
5. 判令被告承担本案诉讼费、保全费、评估费。
```

**要点**：
- 财产分割不要写"依法分割"就完事，要附**财产清单**并明确主张的归属和补偿数额，否则法院可能只判"另案处理"。
- 精神损害赔偿要**在离婚诉讼中同时提出**（解释（一）第 88 条），另案起诉会被驳回。
- 不要在一开始就把所有底牌写进起诉状，但**诉讼请求不能事后随意增加**（增加要在举证期限届满前）。

### 3.4 保全

**什么时候申请**：发现对方正在转移存款、过户房产、注销公司、大额取现。

**怎么申请**：
- 诉前保全：立案前向法院申请，**30 日内必须起诉**，否则解除。
- 诉中保全：立案同时或举证期限内申请。
- 担保：现金、房产、保全责任险（保费约为保全金额 0.1%–0.3%）。
- 费用：1000 元以下 30 元；1000 元–10 万按 1%；超 10 万按 0.5%；上限 5000 元。

**风险**：保全错误造成对方损失要赔。**只保全有依据的财产，不搞漫天撒网式施压。**

### 3.5 调查令

北京多数基层法院在离婚案件中可签发调查令。申请书要写清：

- 查询对象（机构名称、地址）
- 查询内容（账户、时间段、具体项目）
- 与本案的关联性（为什么这项证据在对方控制下、为什么自己取不到）

**常查的六类**：
1. 银行流水（近 2–5 年，重点看大额转出）
2. 不动产登记（对方名下是否有隐藏房产）
3. 车辆登记
4. 证券、基金账户
5. 工商档案（股权、变更、对外投资）
6. 社保、公积金、个税（核定收入）

**调查令拿不到的**（法院也很少批）：酒店开房记录、通话记录、航班记录、微信/支付宝完整流水（部分法院支持查支付宝）。**别向当事人承诺"都能查到"。**

### 3.6 庭审要点

**法官一定会问的八个问题**，提前让当事人准备好答案：

1. 什么时候认识、什么时候登记、初婚还是再婚？
2. 婚后感情怎么样，什么时候开始出问题？
3. 因为什么分居，分居多久，现在住哪？
4. 还有没有和好的可能？
5. 孩子一直谁带，在哪上学，你打算怎么带？
6. 房子什么时候买的，谁出的钱，登记在谁名下，谁在还贷？
7. 双方名下还有哪些财产、有没有外债？
8. 你对离婚是什么态度？

**举证质证的三板斧**：

- **真实性**：是不是原件？有没有剪辑？形成时间？——打聊天记录截图、打录音片段。
- **合法性**：怎么取得的？有没有侵入私密空间？——打偷拍、打购买的开房记录。
- **关联性**：想证明什么？和本案争议焦点有关系吗？——打"对方三年前的一次暧昧聊天"。

**不要把战场铺太宽**。离婚案的核心争议焦点通常只有三个：离不离、孩子归谁、财产怎么分。其他都是枝节。

### 3.7 调解

- 法院审理离婚案件**应当调解**（民法典第 1079 条）。
- 调解可以贯穿全程，二审也可以调解。
- **调解书与判决书同等效力**，可直接申请执行。
- 调解的优势：快、可执行、可谈出判决拿不到的条件（如一次性付款、股权转让、探望安排）。
- 调解的陷阱：为了快速结案接受"分期付款 + 无违约条款"，对方拖着不付，你还得再诉。

## 四、谈判技巧

### 4.1 三条铁律

1. **先算 BATNA**。谈不成打官司能拿到什么，就是你的底线。没有 BATNA 的谈判就是投降。
2. **锚定要早、要高、要有依据**。"我要 300 万"没人信；"按第 78 条算法，共同还贷本息 97.2 万，对应增值 100%，我应得 97.2 万，我主张 95 万"才有说服力。
3. **每一次让步都换对等条件**。无条件让步只会让对方确认你还有空间。

### 4.2 可让与不可让

| 可以让 | 不能让 |
|---|---|
| 付款时间、分期安排 | 抚养权归属（如果是核心诉求） |
| 家具家电、车辆 | 房产归属（如果是主要财产） |
| 探望的具体时间微调 | 抚养费的一次性买断 |
| 债务的分担比例（对内） | 一次性大额款项的支付保障 |
| 户口迁移期限 | 违约条款（必须写） |
| 精神损害赔偿的数额 | 已查明的转移财产不追究 |

### 4.3 谈判节奏

```
第 1 轮：亮证据、亮底线、给对方算一遍账（让他知道打下去更亏）
第 2 轮：抛出方案 A（对你有利），说明为什么合理
第 3 轮：对方还价，记录，不急着回应
第 4 轮：方案 B（你的真实目标），用"可以马上签字"换对方的确定性
第 5 轮：细节条款拉锯（付款节点、违约、过户税费）
```

**永远不要在对方情绪激动时谈核心条款**。家暴案、出轨案尤其——对方一激动就谈崩，改天再谈。

**永远把所有让步写进纸面**。口头承诺在法庭上等于零。

### 4.4 冷静期是谈判窗口

30 天冷静期不是"等"，是**最后一次低成本谈判的机会**。这 30 天里：

- 把没查清的财产查清（很多人在冷静期才发现对方藏了钱）
- 把协议条款请律师过一遍
- 如果发现对方在转移财产，立即停止协议、转诉讼 + 保全

**注意**：冷静期内签的任何补充协议，都可能被对方主张"已达成一致"，签字前想清楚。

## 五、判决之后

| 结果 | 下一步 |
|---|---|
| 判离 + 财产分割 | 15 日内决定是否上诉；不上诉则生效，对方不履行 2 年内申请执行 |
| 判不离 | 6 个月后可再诉；这 6 个月用来补证据、稳抚养事实、查财产 |
| 部分支持 | 对不服部分上诉（注意：二审可能全面审查） |
| 调解结案 | 直接生效，可申请执行 |

**上诉的决策逻辑**：一审明显认定事实错误或适用法律错误才上诉。仅"觉得分少了"上诉，二审大概率维持，还多花 3 个月。

## 六、执行

- 申请期限：**2 年**，从法律文书规定履行期间最后一日起算。
- 可执行财产：银行存款、房产、车辆、股权、工资、公积金。
- 强制措施：查询冻结划拨、查封拍卖、限制高消费、纳入失信名单、司法拘留。
- **抚养权、探望权不能对人身强制执行**（解释（一）第 68 条），只能通过变更抚养、罚款拘留妨害方间接施压。

## 七、给当事人的时间表（直接照着念）

> 第 1 周：把证据固定住（伤情、聊天记录、流水）。
> 第 2 周：查清财产（房产、车辆、账户、股权）。
> 第 3–4 周：决定走协议还是诉讼；走诉讼的，准备起诉状和保全。
> 第 2 个月：立案、保全、申请调查令。
> 第 3–5 个月：开庭。
> 第 6–8 个月：判决、上诉期、生效。
> 判不离的，第 7 个月准备第二次起诉。
