# 证据清单与取证边界

> 一句话原则：**能拿到、拿得合法、拿得住原始载体**，三者缺一，证据等于没有。

---

## 一、三条总原则

### 1. 合法性不是"能不能用"，是"会不会反噬"

《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第 106 条：

> 对以严重侵害他人合法权益、违反法律禁止性规定或者严重违背公序良俗的方法形成或者获取的证据，不得作为认定案件事实的根据。

所以取证前先问三句：**侵入别人的私密空间了吗？违反法律禁止性规定了吗？严重违背公序良俗了吗？** 三句有一句是"是"，就不要做。

### 2. 原始载体 > 截图 > 转述

微信聊天记录只交截图，对方一句"P 的"就可能被质疑。正确做法：**保留原手机 + 当庭演示 + 公证或可信时间戳固定**。录音要保留原始录音设备里的文件，不要只交转存版。

### 3. 证据要成链，不要成点

一条"他给小三转了 5200"的截图，只能证明一笔钱。要打成"出轨 + 转移财产"，需要：转账记录 + 聊天记录 + 开房/同住证据 + 时间线 + 对方承认的录音。**单点证据在法庭上几乎无用。**

## 二、分类证据清单

合法性标注：**合法** = 可以放心做；**灰色** = 可能被质疑甚至不采纳，一般不追责，但要想清楚；**违法** = 明确不要做。

### A. 身份与婚姻关系

| 证据 | 证明什么 | 怎么拿 | 合法性 |
|---|---|---|---|
| 结婚证 | 婚姻关系成立 | 自己手里 | 合法 |
| 婚姻登记记录证明 | 结婚证遗失时补位 | 原登记机关或档案馆调取 | 合法 |
| 身份证、户口本 | 主体身份、子女关系 | 自己手里 | 合法 |
| 子女出生医学证明 | 亲子关系、出生时间 | 自己手里；遗失可到医院/卫健部门调 | 合法 |
| 居住证明 / 暂住证 | 管辖（经常居住地） | 社区、派出所开 | 合法 |
| 婚姻无效 / 可撤销的证据 | 重婚、禁婚亲属、未到婚龄、胁迫、隐瞒重大疾病 | 结婚登记档案、刑事判决、医院病历 | 合法 |

### B. 夫妻共同财产（主战场）

| 证据 | 证明什么 | 怎么拿 | 合法性 |
|---|---|---|---|
| 不动产登记簿 | 房产权属、登记时间、抵押 | 本人可查名下；对方名下需**律师调查令/法院调查** | 合法 |
| 购房合同、发票、契税票 | 购买时间、价格、出资 | 家中文件、开发商、税务 | 合法 |
| 首付转账凭证 | 出资来源（父母出资的关键） | 银行打印，须盖章 | 合法 |
| 贷款合同、还贷流水 | 共同还贷金额（算补偿的基数） | 贷款银行打印 | 合法 |
| 银行账户流水（近 2–5 年） | 存款、异常转账、取现 | 自己账户直接打；对方账户申请**调查令** | 合法 |
| 理财 / 基金 / 股票对账单 | 投资性财产 | 自己操作的可截图；对方的走调查令 | 合法 |
| 公积金缴存明细 | 共同财产 | 公积金中心，凭身份证或调查令 | 合法 |
| 社保缴费记录 | 收入水平、工作单位 | 社保中心 / 北京通 | 合法 |
| 工商档案（章程、股东名册、变更记录） | 股权、代持、抽逃出资 | 国家企业信用信息公示系统 + 市场监管局调档 | 合法 |
| 公司财务报表、分红记录 | 股权价值 | 调查令；或审计 | 合法 |
| 车辆登记信息 | 车辆权属 | 车管所，需调查令 | 合法 |
| 保单及现金价值表 | 保险权益 | 保险公司；或调查令 | 合法 |
| 贵重物品照片、发票、鉴定证书 | 首饰、字画、名表 | 家中拍摄 + 购买凭证 | 合法 |
| 财产约定 / 婚前协议 | 排除法定财产制 | 原件 | 合法 |
| 对方亲口承认财产状况的录音 | 补强 | 自己参与的对话录音 | 合法 |

**关键提醒**：**父母出资**是房产案第一大争点。要固定：转账备注（"购房款""首付"）、转账时间与购房合同时间是否吻合、父母是否有书面赠与/借款说明、当时的家庭对话。事后补的借条基本没用。

### C. 对方过错（出轨类）

| 证据 | 证明什么 | 怎么拿 | 合法性 |
|---|---|---|---|
| 微信 / 短信聊天记录 | 关系性质、约定、承认 | 自己手机上的原始记录；**保留原机** | 合法 |
| 转账记录（520、1314、大额） | 赠与第三者、转移财产 | 自己账户流水；对方账户走调查令 | 合法 |
| 电商订单、外卖、打车、酒店订单 | 共同生活轨迹 | 自己账号内的（如家庭共用账号） | 灰色偏合法 |
| 公开场合的同行照片、视频 | 关系密切 | 公共场合自行拍摄 | 合法 |
| 小区监控、门禁记录 | 同进同出、共同居住 | 物业调取（需正当理由），或申请法院调取 | 合法 |
| 邻居、保安、同事证言 | 持续共同居住 | 书面证言 + 出庭 | 合法 |
| 对方书写的保证书、悔过书 | 直接承认 | 让对方手写（不要逼、不要打） | 合法 |
| 对方承认的录音 | 直接承认 | 自己参与的对话录音（不剪辑） | 合法 |
| 酒店开房记录 | 同住 | **只能**通过法院调查令向公安/酒店调取 | 合法（走调查令）；自行购买属**违法** |
| 航班、高铁同行记录 | 共同出行 | 调查令 | 合法 |
| 非婚生子女的出生医学证明 | 重婚/同居的铁证 | 医院、卫健部门（需调查令） | 合法 |
| 重婚的结婚登记记录 | 重婚罪、1091 条 | 民政部门（需调查令） | 合法 |

**必须讲清的法律边界**：民法典第 1091 条的"与他人同居"= **有配偶者与婚外异性，不以夫妻名义，持续、稳定地共同居住**（解释（一）第 2 条）。**偶发出轨、约炮、暧昧聊天，不构成法定赔偿情形**。它的价值在：谈判筹码、抚养权加分、追回赠与第三者的财产（解释（二）第 7 条）。

### D. 家庭暴力（最值钱的一组证据）

| 证据 | 证明什么 | 怎么拿 | 合法性 |
|---|---|---|---|
| 110 接处警记录 / 出警记录 | 报警事实、时间、地点 | 派出所调取，要**盖章**的那份 | 合法 |
| 询问笔录 | 双方陈述 | 派出所复印（本人可调） | 合法 |
| 家庭暴力告诫书 | 公权力认定 | 派出所出具 | 合法 |
| 伤情照片 | 伤害程度 | 当天拍，带时间水印，多角度，含面部 | 合法 |
| 医院病历、诊断证明 | 伤情、就诊时间 | 就诊时明确告知"被配偶殴打"并要求记载 | 合法 |
| 法医人体损伤鉴定 | 轻微伤/轻伤 | 派出所委托或自行委托 | 合法 |
| 录音录像 | 施暴过程、威胁 | 自己家中录制；手机随手录 | 合法 |
| 施暴者悔过书、保证书 | 承认施暴 | 让其手写，注明时间 | 合法 |
| 微信威胁、辱骂记录 | 精神暴力 | 原始记录 + 原机 | 合法 |
| 邻居、子女、保姆证言 | 长期性、经常性 | 书面 + 出庭 | 合法 |
| 妇联、居委会、村委会记录 | 求助记录 | 相关机构调取 | 合法 |
| 庇护所入住记录 | 避险事实 | 庇护机构 | 合法 |
| 人身安全保护令裁定 | 司法认定 | 法院 | 合法 |

**解释（一）第 1 条**：持续性、经常性的家庭暴力，可以认定为"虐待"。这意味着**一次轻微冲突不够**，要证明"持续性、经常性"——所以每次都要报警、每次都要留痕。

### E. 抚养权

| 证据 | 证明什么 | 怎么拿 | 合法性 |
|---|---|---|---|
| 日常照料照片、视频 | 谁在实际带孩子 | 自己拍摄，带时间 | 合法 |
| 幼儿园/学校接送记录 | 谁接送 | 学校门禁、家长签到、老师证言 | 合法 |
| 家长群聊天记录 | 谁在对接老师 | 自己手机 | 合法 |
| 就医记录（谁带孩子看病） | 照料事实 | 医院挂号、缴费记录 | 合法 |
| 疫苗接种记录 | 照料事实 | 接种证、社区卫生服务中心 | 合法 |
| 居住证明、学区证明 | 稳定生活环境 | 房产证、租赁合同、居委会 | 合法 |
| 收入证明、纳税记录、社保 | 抚养能力 | 单位、税务、社保 | 合法 |
| 祖父母/外祖父母协助抚养的证明 | 优先条件（解释（一）第 47 条） | 居住证明、证言 | 合法 |
| 对方不良行为证据 | 不利于子女 | 见 C、D 类 | 合法 |
| 对方长期不回家、不支付的记录 | 未尽抚养义务 | 聊天记录、转账记录 | 合法 |
| 八周岁以上子女的意愿 | 法院应尊重 | 由法院询问，**不要教孩子说话** | 合法 |

### F. 债务

| 证据 | 证明什么 | 怎么拿 | 合法性 |
|---|---|---|---|
| 借条、借款合同 | 债务存在 | 原件；对方持有的走调查令 | 合法 |
| 转账凭证、资金流向 | 债务真实性 | 银行流水 | 合法 |
| 借款用途证据 | 是否用于共同生活/经营 | 消费记录、经营账目 | 合法 |
| 债权人证言、到庭陈述 | 真实性 | 申请证人出庭 | 合法 |
| 赌债、毒资的线索 | 排除共同债务 | 报警记录、转账对象 | 合法 |

### G. 对方妨碍诉讼 / 转移财产

| 证据 | 证明什么 | 怎么拿 | 合法性 |
|---|---|---|---|
| 大额取现、转账记录 | 转移财产（1092 条） | 银行流水（调查令） | 合法 |
| 房产、车辆过户记录 | 变卖共同财产 | 登记部门（调查令） | 合法 |
| 公司股权变更、注销记录 | 隐匿经营资产 | 工商档案 | 合法 |
| 虚假债务的借条与流水 | 伪造债务 | 调查令 + 鉴定 | 合法 |
| 财产申报表（不实申报） | 少分不分的依据 | 庭审中要求填报 | 合法 |
| 对方拒不到庭、拒不申报 | 不利推定 | 庭审笔录 | 合法 |

## 三、取证红线（明确违法，做了会反噬）

| 行为 | 违法点 | 后果 |
|---|---|---|
| 破解对方手机、微信、邮箱密码 | 可能构成非法获取计算机信息系统数据（刑法第 285 条）；侵犯隐私（民法典第 1032 条） | 证据可能被排除，自己可能被追责 |
| 在第三者住处、酒店房间安装摄像头 | 非法侵入住宅 / 侵犯隐私 | 证据排除，可能治安处罚甚至刑责 |
| 在对方车辆安装 GPS 跟踪器 | 行踪轨迹属敏感个人信息（个人信息保护法） | 证据排除，可能被索赔 |
| 购买开房记录、通话记录、航班记录 | 侵犯公民个人信息（刑法第 253 条之一） | 情节严重可构成犯罪 |
| 雇佣"私家侦探"跟踪偷拍 | 我国无合法私家侦探；手段多涉违法 | 证据风险高，可能连带担责 |
| 破门而入、暴力抢夺孩子 | 非法侵入住宅、故意伤害、抢夺 | 抚养权上直接失分，还可能被保护令 |
| 在对方单位、小区张贴大字报 | 名誉权侵权（民法典第 1024 条） | 反被起诉赔偿 |
| 胁迫、殴打对方写下"净身出户"承诺 | 意思表示不真实（民法典第 143 条） | 协议可撤销，还可能涉刑 |
| 伪造证据、指使他人作伪证 | 妨害作证、伪造证据 | 罚款、拘留，严重的追刑责 |

**灰色地带怎么处理**：确实需要时，先评估"这份证据值多少钱"和"被反诉的风险有多大"，再决定。**能用调查令拿到的，一律走调查令**——合法、干净、法院认可。

## 四、电子证据固定方法

1. **保留原始载体**：不要换手机、不要恢复出厂、不要删聊天框。
2. **当庭演示**：开庭带原机，登录账号，当庭打开原始对话。
3. **公证**：到公证处做"网页/聊天记录/录音"保全公证，几百到几千元，证明力最强。
4. **可信时间戳**：成本低，可证明"某时点已存在该内容"，适合量大时批量固定。
5. **录屏**：从打开 App 到点开对话到转账详情，全程一镜到底，不要剪辑。
6. **录音规范**：自己参与的对话可以录（合法）；不要剪辑、不要只保留片段、保留原始文件；转录文字要逐字对应。
7. **转账记录**：银行打印的**盖章流水** > App 截图。截图要含户名、账号、时间、金额、余额。

## 六、办案时的取证优先级

时间有限、资源有限时，按这个顺序做：

1. **先固定会消失的**：伤情（会好）、聊天记录（会删）、监控（会覆盖）、对方账户异常转账（会继续转）。
2. **再固定要公权力的**：报警记录、告诫书、保护令、调查令。
3. **再固定财产**：房产、车辆、股权、流水。
4. **最后补证人证言**：证人会反悔、会被人做工作，越晚越不可靠。
